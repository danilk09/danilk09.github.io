I am currently constructing a text-based game with C and SQLite to help imrpove reading comprehension speed of hiragana and katakana Japanese characters. The logic of the game is to provide words written in hiragana or katakana, then the user has to respond with the romaji version of the word. The faster a user answers, the more points they gain. Currently, the game can be played using the terminal; however, I want to make it accessible through discord. Therefore, I am creating a Python coded Discord bot that acts as the intermediary between the user and the game.
